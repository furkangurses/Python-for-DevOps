
# Python Project for AI Application Development

This repository contains the projects and laboratory exercises completed as part of the **Python Project for AI Application Development** course, offered by IBM through Coursera. This course is a core component of the *IBM DevOps and Software Engineering Professional Certificate*.

## 🚀 Project Overview

The primary goal of this project is to apply software engineering best practices to develop and deploy Python-based applications suitable for AI integration. Throughout the course, I focused on building modular, testable, and deployable code.

### Key Learning Objectives:
* Developing and modularizing Python applications.
* Implementing **Unit Testing** using the `unittest` framework to ensure code reliability.
* Creating web interfaces using the **Flask** framework.
* Applying **Static Code Analysis** (using tools like `pylint`) to maintain high coding standards.
* Packaging Python applications for distribution.

## 🛠️ Technologies & Tools

* **Language:** Python 3.x
* **Web Framework:** Flask
* **Testing:** Unittest
* **Code Quality:** Pylint
* **Environment:** Linux / Git
